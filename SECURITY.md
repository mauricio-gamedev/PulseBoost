# Segurança e autenticidade

## Versões oficiais

Considere oficial somente uma versão publicada por **[@astromg01](https://github.com/astromg01)** no repositório `astromg01/PulseBoost`.

O APK beta oficial é assinado pelo certificado SHA-256:

`c7b91f53e1b68897f11ec878afd6bc9af18720bf336544280f5254647c27b19e`

As chaves privadas e senhas de assinatura nunca fazem parte do repositório público. Um clone que produza outro certificado não representa uma versão oficial.

## Relato responsável

Não publique detalhes exploráveis de uma vulnerabilidade ainda não corrigida. Entre em contato com @astromg01 por um canal privado do GitHub quando disponível, informando versão afetada, impacto e passos mínimos para reprodução.

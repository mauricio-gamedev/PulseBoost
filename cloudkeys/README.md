# CloudKeys MVP-0

Technical prototype for a floating keyboard shortcut overlay over cloud gaming.

Core test:

[I] -> Shizuku UserService -> /system/bin/input keyevent 37 -> Android input -> GeForce NOW/game.

The cursor is not manipulated by the app. The overlay only owns the shortcut button.

Build target: Android 16 / API 36.
Minimum: Android 7.0 / API 24.

The APK is generated by GitHub Actions from the cloudkeys-mvp-0 branch.
